# Актуальность документации и история

## Базовая версия

Текущая документация сверена с `master`, коммит `a3401ce`, 30.10.2026. Ссылки на исходники закреплены за этой ревизией. Тестовый результат: 735 тестов SQLite Release без ошибок/пропусков; [подробности](testing.md).

## Что изменилось относительно старой документации

- Запуск использует .NET 10, рабочие серверное решение и Dockerfile, runtime-секреты, отключаемый Firebase, migrate-only и readiness.
- Регистрация транзакционно расходует приглашение и добавляет обязательный канал.
- HTTP проверяет активную сессию; refresh имеет случайный jti и условную ротацию; хабы проверяют сессию перед командой.
- История проверяет доступ и сортируется по (SentAt, Id); вложения проверяют владельца.
- Реализованы E2EE, сертификаты/ротация устройств, зашифрованный архив, SRP-вход, парольная копия кода и явный сброс ключей.
- Исправлены зависимости HTTP presence, старого API ключей, обработка ошибок профиля и HTTP ServerError.
- Справочники групп, реакций, прочтения и push включены в общую навигацию.

Ранняя диагностика `4603be9` и список исправлений 03.10.2026 были историческими снимками. Они заменены актуальной [диагностикой](diagnostics.md), а не оставлены как параллельный контракт API. Историю реализации смотрите в Git.

## Как поддерживать документацию

При изменении маршрута, DTO, прав, событий или конфигурации обновляйте соответствующую страницу, [карту API](api-reference.md), [путь интеграции](client-integration.md) и FAQ, если меняется пользовательский сценарий. Отделяйте проверенные результаты от планов. Не обновляйте дату проверки без чтения кода и выполнения относящихся к изменению проверок.

`docs/SUMMARY.md` задаёт навигацию. Сохраняйте прежние страницы как короткие ссылки на канонический раздел, если их URL уже использовались; не храните две независимые копии контракта. Локальные ссылки должны вести на страницы внутри docs либо на исходники по полному GitHub URL.

## GitBook и репозитории

На момент проверки GitBook Govor-API имеет активный Git Sync с `Govor-team/Govor`, веткой `master`, каталогом `docs`. Проверенный здесь код находится в `stalcker2288969/Govor`. Это разные репозитории; push в текущий origin сам по себе не обновляет подключённое пространство.

Настройка Git Sync меняется в интерфейсе GitBook. Владельцу нужно выбрать единый канонический репозиторий и синхронизировать с ним документацию, иначе последующий импорт старой ветки может вернуть устаревший текст. Эта переработка не переключает Git Sync и не меняет права интеграции.

## Изменение публичных адресов

Страницы сгруппированы под началом работы, аутентификацией, E2EE, HTTP API, SignalR и развёртыванием. ID существующих страниц сохранены, внутренние ссылки GitBook используют стабильные ID. Автоматические site redirects недоступны на текущем тарифе; внешние закладки/ссылки на старые пути нужно обновить либо настроить redirects после подключения подходящего тарифа.
