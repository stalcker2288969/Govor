# Друзья и поиск

Bearer token обязателен; отдельная роль в атрибуте не задана.

| Метод | Маршрут | Результат |
| --- | --- | --- |
| GET | /api/friends | UserDto[] друзей |
| GET | /api/friends/search?query=Арт | UserDto[] результатов поиска |

```json
[{
  "id":"11111111-1111-1111-1111-111111111111",
  "username":"Артём",
  "description":"",
  "wasOnline":"2026-10-03T00:00:00Z",
  "iconId":"00000000-0000-0000-0000-000000000000",
  "isOnline":false
}]
```

Пустой/пробельный query возвращает 400 строкой "Query cannot be empty". Успех — 200; серверные ошибки — 500 с объектом error. Не смешивайте UserDto и UserProfileDto: у второго нет wasOnline.

Изменение заявок выполняется через FriendsHub. HTTP-контроллер не содержит команды отправки, принятия и отклонения.

Статус isOnline зависит от состояния процесса и подключения к presence. Он не является гарантией доставки сообщений или фоновой доступности устройства.

## Удаление из друзей и блокировка

| HTTP                                 | Действие                     |
| ------------------------------------ | ---------------------------- |
| `DELETE /api/friends/{userId}`       | Удалить принятую дружбу      |
| `PUT /api/friends/{userId}/block`    | Заблокировать пользователя   |
| `DELETE /api/friends/{userId}/block` | Снять собственную блокировку |

Успех — `204`. Идентификатор текущего пользователя всегда берётся из JWT. Пустой ID и действие на себя дают `400`; блокировка несуществующего пользователя — `404`; изменение чужой блокировки — `403`.

Удаление идемпотентно, переводит принятую дружбу в `Rejected`, сохраняет историю чата и не снимает блокировку. Само удаление дружбы не запрещает отправку в ранее созданный чат: для этого нужна блокировка. Блокировка может создаваться без дружбы, исключает пользователя из друзей и запрещает новые сообщения в личном чате в обе стороны, а также новые заявки. Чтение истории и общие группы сохраняются.

Используется существующая модель `FriendshipStatus.Blocked`: у пары одна блокировка, её владелец записан как `RequesterId`. Только владелец может снять её; вторая сторона не может заменить владельца. Повтор собственной блокировки безопасен. Снятие блокировки не восстанавливает дружбу: требуется новая заявка и согласие получателя.
