# Профильные теги

У каждого пользователя один настраиваемый профильный тег. Изменение доступно при Govor+ или отдельном праве CustomProfileTag. [Назначение и проверка прав](README.md).

## Изменение и сброс

`PUT /api/profile/tag` заменяет оформление текущего пользователя. Текущий пользователь берётся из access JWT. Передайте непосредственно объект оформления:

```json
{
  "text": "Govor+",
  "textColor": "#FFFFFF",
  "textGradientEndColor": null,
  "backgroundColor": "#2455DD",
  "gradientEndColor": null,
  "gradientAngle": 90,
  "borderColor": "#6688FF",
  "borderGradientEndColor": null,
  "borderWidth": 1,
  "shadowColor": "#00000080",
  "shadowBlur": 4,
  "shadowOffsetX": 0,
  "shadowOffsetY": 1,
  "fontFamily": "Inter",
  "fontWeight": 600,
  "fontSize": 12
}
```

Пропущенные поля получают стандартные значения. `DELETE /api/profile/tag` сбрасывает оформление к стандартному. Оба endpoint возвращают 200 с актуальным UserBenefitsView. Без права настройки — 403; некорректное оформление — 400 без изменения сохранённого тега.

## Параметры оформления

| Параметр                                         | Допустимое значение                                                         |
| ------------------------------------------------ | --------------------------------------------------------------------------- |
| `text`                                           | 1–32 UTF-16 символа, не пробельная строка, без управляющих символов         |
| Цвета                                            | `#RRGGBB` или `#RRGGBBAA`                                                   |
| `gradientEndColor`                               | Конечный цвет градиента фона; `null` — сплошной фон                         |
| `textGradientEndColor`, `borderGradientEndColor` | Конечные цвета градиентов текста и обводки; `null` — сплошной цвет          |
| `gradientAngle`                                  | 0–360°, общий угол линейных градиентов                                      |
| `borderWidth`                                    | 0–4                                                                         |
| `shadowBlur`                                     | 0–20                                                                        |
| `shadowOffsetX`, `shadowOffsetY`                 | −10–10                                                                      |
| `fontFamily`                                     | `Inter`, `Roboto`, `Arial`, `Noto Sans`, `serif`, `sans-serif`, `monospace` |
| `fontWeight`                                     | 100–900 с шагом 100                                                         |
| `fontSize`                                       | 10–24                                                                       |

Размеры заданы в логических пикселях. Угол соответствует CSS linear-gradient: 0° вверх, 90° вправо. Клиент обеспечивает наличие выбранного шрифта или безопасный fallback. Тег — структурированные данные: текст рендерится как plain text, а не HTML; URL шрифтов, произвольный CSS и внешние ресурсы не принимаются. Некорректное оформление даёт `400` и не изменяет сохранённый тег.

При отзыве прав сохранённое оформление остаётся в БД, но скрывается в API и не может редактироваться. При повторной выдаче права оформление восстанавливается.

## Отображение

Официальный статус определяйте по benefits.isGovorPlus, а не по тексту тега. Текущий стиль доступен в benefits.tag при чтении профиля или `GET /api/profile/{userId}/benefits`. После изменения или сброса сервер отправляет UserBenefitsUpdated в /hubs/profiles.
