# Обновления статуса и тега

Подключите каждый клиент к `/hubs/profiles` и слушайте `UserBenefitsUpdated`:

```javascript
connection.on("UserBenefitsUpdated", ({ userId, benefits }) => {
  const old = profileBenefits.get(userId);
  if (!old || benefits.revision > old.revision) {
    profileBenefits.set(userId, benefits);
    refreshVisibleUserTags(userId);
  }
});
```

Событие содержит полный объект, включая `revision`, и отправляется **всем** подключённым авторизованным клиентам этого хаба, включая владельца, после фиксации выдачи/отзыва прав, изменения или сброса тега. Дружба или подписка на конкретный профиль не требуется. Статус и тег — публичные данные для авторизованных пользователей. Обновляйте общий кеш профилей и все места отображения пользователя: чат, список участников, друзей и открытый профиль. HTTP-ответ содержит тот же формат.

Ревизия монотонно увеличивается на пользователя; игнорируйте события и HTTP-снимки с меньшей или равной ревизией. Это защищает от изменения порядка доставки при конкурентных запросах. Сначала зарегистрируйте обработчик, подключитесь, затем загрузите HTTP-снимки, также сравнивая ревизии.

SignalR не хранит историю событий: после восстановления соединения перечитайте видимые профили/benefits через HTTP. При сбое доставки сохранённый HTTP-запрос остаётся успешным, ошибка пишется в серверный лог; снимок в БД является источником истины. Перезапуск API для выдачи статуса или изменения оформления не нужен. При запуске нескольких экземпляров API необходим общий SignalR backplane/service для доставки между экземплярами; текущая конфигурация использует стандартный in-process SignalR.

## Формат события

Имя события: `UserBenefitsUpdated`. Payload — `{ userId, benefits }`, где benefits содержит privileges, isGovorPlus, canCustomizeProfileTag, tag и revision. Например, отзыв всех прав:

```json
{
  "userId": "<user-id>",
  "benefits": {
    "privileges": 0,
    "isGovorPlus": false,
    "canCustomizeProfileTag": false,
    "tag": null,
    "revision": 4
  }
}
```

Операции записи выполняются через HTTP. Команд SetTag или SetPrivileges на ProfileHub нет. [Модель привилегий](README.md).
